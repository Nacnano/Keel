# Detection accuracy

Generated by `pnpm eval` (eval/run.ts) on 2026-10-24 at commit `893a313`. 10 sessions, 299 s of piano at 48 kHz, rendered from the Splendid Grand Piano samples the app uses. See eval/README.md for the sessions, conditions and metric definitions.

## Scope and limitations

These are deterministic simulated performances, not recordings of people jamming. The ten progressions and noise conditions were also used during tuning, so the results are development-set measurements, not an independent accuracy guarantee. The baseline uses the same renderer, seeds, sample recordings, metric code and configurations as the improved detector. Low-level conditions are peak dBFS; noise SNR is measured against whole-session RMS.

Chord accuracy includes transitions and display delay; the after-0.5-second column excludes the first 500 ms of each written chord. Latency is conditional on finding the chord and must be read alongside missed changes. Ground truth is the written harmony: melody, pedal overlap, inversions and inherently ambiguous voicings can make another label defensible. Nine sessions are major and only one is minor; exact-key results are especially limited by that imbalance. A major-key prior and relative-key switching hysteresis are part of the estimator.

No real microphone, browser capture chain, device processing, guitar recordings, live singers, speech or percussion are represented in the primary matrix. The vocal distractor is a simple synthesized voice. Room mode is a heuristic, not source separation. Sensitivity changes gate opening, not chord vocabulary or input gain; the headline runs use its default 0.5. The adaptive gate learns the initial room floor, so a brief quiet lead-in helps quiet playing. Real-device and held-out musician recordings are still required before claiming field accuracy.

## Reading these results

The detector remains imperfect: repeated mains hum can dominate the bass and harmonic evidence, and pedal, broken chords and rootless jazz voicings still produce wrong labels. Room mode helps the simulated vocal distractor but does not consistently improve the speaker condition. In quiet/speaker conditions the original fixed gate mostly showed dashes; opening it increases both correct detections and opportunities for spurious labels. Compare chord accuracy, dash time and spurious changes together. A short latency among detected changes does not include missed changes.
